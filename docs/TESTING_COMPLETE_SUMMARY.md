## 部署验证

### 启动步骤

```bash
# 1. 安装依赖
cd background
pip install -r requirements.txt

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，设置 SECRET_KEY

# 3. 启动应用
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# 4. 验证应用
# 访问 http://localhost:8000/docs 查看 API 文档
```
